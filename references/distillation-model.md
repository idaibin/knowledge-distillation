# Distillation Model v0.1

Use this model after defining the source boundary.

## 1. Claims and Evidence

Extract atomic claims. Attach at least one evidence record to each principle, framework, and anti-pattern.

- `citation`: traceable published or supplied source.
- `experience`: named personal or organizational practice.
- `observation`: directly observed behavior or result.
- `inference`: synthesis derived from other evidence; state the reasoning in `note`.

Do not upgrade an inference into a source claim.

## 2. Principles

Keep a principle only when it changes how a user interprets or evaluates a situation. Prefer one falsifiable statement over a slogan or quotation.

## 3. Frameworks

A framework must solve a named problem. Every step needs:

- an action;
- a check that can change the next decision;
- at least one boundary describing when the framework should not be applied.

Do not turn a topical outline into a decision framework.

## 4. Anti-Patterns

Record a recognizable symptom and a corrective action. Avoid moral labels or generic warnings.

## 5. Open Questions

Preserve gaps, contradictions, missing evidence, and unresolved scope. Compression must not erase uncertainty.

## 6. Executable Capability

Compile Level 4 only when the knowledge supports:

- reliable trigger and non-trigger conditions;
- explicit required inputs;
- ordered steps with stable intent;
- output contract;
- constraints and stop conditions;
- behavioral tests with observable expectations.
