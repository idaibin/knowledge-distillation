# AI Engineering Reliability Patterns

This directory contains small, reusable engineering rules distilled from repeated AI-assisted software work. A pattern is not a course note or a prompt. It names a failure mode, defines an evidence-backed response, and states how to tell whether the response worked.

Start with:

- [Evidence Loop](evidence-loop.md): prevent plausible but unsupported findings.
- [Fixed-Basis Review](fixed-basis-review.md): keep review results reproducible while repository state changes.

These patterns are inputs to Skills and experiments. They do not replace repository-specific instructions, runtime verification, or human adjudication.
